# Interactive Pricing Plans

A responsive and interactive pricing plans website built using **HTML, CSS, and JavaScript** as part of **Internify Internship – Task 2**.

The project demonstrates dynamic pricing, category filtering, responsive design, CSS animations, and JavaScript DOM manipulation.

## 🚀 Features

* 💳 4 interactive pricing cards
* 🔄 Monthly / Yearly pricing toggle
* 🏷️ Category filter: All, Basic, Premium
* ⭐ Most Popular plan badge
* ✨ Card hover animations
* 🖱️ Interactive filter button states
* 🎯 CTA button micro-interaction
* 📱 Fully responsive layout
* 🎨 Modern and clean UI
* ⚡ Dynamic content updates using JavaScript

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript
* Font Awesome
* Google Fonts – Poppins

## ⚙️ How It Works

### Monthly / Yearly Toggle

The pricing toggle uses JavaScript to dynamically update the prices when switching between monthly and yearly billing.

### Category Filter

The filter buttons allow users to display:

* All plans
* Basic plans
* Premium plans

The cards are filtered dynamically using JavaScript DOM manipulation.

### Responsive Design

The layout uses CSS Grid and responsive media queries to adapt the pricing cards for:

* Desktop
* Laptop
* Tablet
* Mobile
* Small mobile screens
